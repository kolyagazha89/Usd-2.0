# USD — три интерактивные концепции

Изолированные React-прототипы главной страницы для выбора визуального направления. Это этап исследования дизайна; рабочее приложение в `frontend/` не изменено. Внедрение выбранной концепции и слияние в `main` требуют решения владельца.

| Вариант | Характер | Интерактивность первого экрана |
| --- | --- | --- |
| A — DARK VELOCITY | Гоночная типографика, красный, динамичная композиция | Импульс, переключение интенсивности, движение знака и плоскости |
| B — OBSIDIAN LUXURY | Тёмная галерея, воздух, тонкая сетка, сдержанная композиция | Переключатель «Знак / Детали», клавиатурные стрелки, импульс |
| C — SONIC IMMERSION | Акустическое пространство, крупная типографика, технические подписи | Регулятор интенсивности, выбор направления, звуковые волны |

Во всех вариантах работают фильтры этапов, фильтры результатов, выбор рекорда, демо медиацентра, мобильное меню и нижняя навигация. Кнопки регистрации, кабинета и публичных профилей открывают существующие маршруты действующего USD. Прототипы не отправляют заявки и не изменяют базу. Примеры новостей, части результатов и других данных явно обозначены в интерфейсе.

## Запуск

```sh
cd design-lab
npm ci
npm run dev
```

Откройте адрес Vite. Параметры страницы:

- `?concept=a`, `?concept=b`, `?concept=c` — отдельные концепции.
- `&device=phone` — интерактивный просмотр ширин 360, 390, 430 и 768 px.
- `&embed=1` — страница без панели сравнения, используется внутри мобильного просмотра.

```sh
npm exec tsc -- --noEmit
npm run build
npm run test:sites
```

React 19, TypeScript, Three.js, GSAP/ScrollTrigger, Lucide. Шрифты Manrope, Oswald, Unbounded и JetBrains Mono включены как локальные зависимости Fontsource; внешние запросы к Google Fonts не нужны. Шрифты распространяются по SIL OFL. GSAP используется по своей стандартной лицензии; при дальнейшем распространении сохранять лицензии зависимостей.

## Сцена и производительность

`core/Stage.tsx` выбирает WebGL или облегчённый Canvas2D. Three.js и GPU-драйвер загружаются динамически после успешной проверки WebGL2. Зарегистрированный знак используется как исходная текстура без изменения цвета; металлическая глубина строится по альфа-контуру оригинала.

При отсутствии WebGL остаются оригинальный знак, математически спроецированные волны, реакция на указатель/прокрутку и кнопка импульса. Интерфейс сообщает «Облегчённый режим». При reduced motion используется неподвижная сцена. Рендер останавливается вне видимой области и в скрытой вкладке; DPR ограничен 1.3 на мобильных и 1.6 на desktop.

Сборка намеренно содержит отдельный большой Three.js chunk; он не входит в стартовый пакет и не загружается в проверенном окружении без WebGL. Итоговый бюджет и внешний вид GPU-сцены нужно подтвердить на настоящих устройствах после выбора концепции.

В исходной теме красный — `#f20c2e`; в концепциях предложен `#E50914` из брифа. Окончательный токен акцента утверждается вместе с концепцией. Сам знак не перекрашен.

## Проверка и следующий этап

См. [аудит и результаты проверки](../docs/design/2026-10-27/AUDIT.md). Облачный Chromium проверен; он не предоставляет WebGL. Нативный Safari/iPhone, GPU-сцена и приватные пользовательские сценарии в этом проходе не подтверждены.

После выбора: сформировать дизайн-систему, переносить компоненты по страницам в рабочий frontend, подключать реальные CMS/API-модели через существующие функции и повторно проверять права, формы, историю конфигураций, приватность и регистрацию. Административная панель остаётся светлой.
