USD — настоящий офлайн-этап

Простая инструкция для администратора и судей. Печать из браузера: Ctrl + P.

Перед этапом: испытайте ноутбук, роутер и два телефона без интернета. Проверьте завершение синхронизации с центральным сервером.

1. Загрузите этап

  1. Установите и запустите Docker Desktop в режиме Linux containers / WSL2. Подключите ноутбук к Wi-Fi роутеру площадки.
  2. Извлеките официальный ZIP и откройте USD-Control.cmd. Нажмите «Войти в USD» и введите почту и пароль администратора сайта.
  3. Выберите опубликованный этап и нажмите «Загрузить этап». Программа скачает подписанный пакет и ключи. Пароль и сеанс администратора хранятся только в памяти.
  4. Выберите подключение к роутеру площадки. Если Windows попросит разрешить доступ в частной сети, подтвердите запрос. Дождитесь статуса «Офлайн-сервер работает».

Подготовка требует интернета. Загруженный этап стартует без интернета. Для прерванной установки нажмите «Продолжить загрузку». Пакет установки действует 72 часа. Если срок истёк, войдите в USD, чтобы получить свежую выгрузку. Не отправляйте файлы судей посторонним. В случае ошибки в окне есть кнопки повтора и копирования подробностей.

2. Обновите существующую установку

  1. На рабочем столе откройте свойства ярлыка «USD — Офлайн-сервер» и найдите путь к папке установленной программы. В новом приложении он также указан в «Диагностика → Технические подробности».
  2. Завершите текущую операцию USD и закройте окно. Извлеките ZIP в отдельную папку и скопируйте из него файлы программы поверх файлов в рабочей папке действующего ярлыка. Сохраните .env, local-private, папки этапов и тома Docker.
  3. Откройте тот же ярлык, проверьте название этапа и нажмите «Установить или обновить сервер». Если сервер уже работает и нужен только новый интерфейс Windows, достаточно открыть ярлык после обновления файлов.

Если Docker потерял контейнер базы, запуск восстанавливает его из сохранённого тома. Если самого тома нет, операция остановится. При повреждении установки передайте подробности администратору USD.

3. Подготовьте справочник и откройте админку

Первая загрузка этапа содержит актуальные на момент выгрузки онлайн-регистрации. Кнопка «Обновить участников и автомобили» дополняет справочник и сохраняет локальные заявки, номера, инспекции и результаты. Поздние онлайн-заявки, которых нет в списке, оформляйте через локальную админку на площадке.

Для повторного запуска нажмите «Запустить офлайн-сервер». После проверки API и HTTPS станут доступными «Открыть локальную админку», «Открыть LIVE-табло» и «Копировать адрес».

4. Откройте на телефонах и LIVE-табло

Сертификат скачивается из онлайн-админки: «Офлайн-сервер» → «Скачать сертификат для телефонов». Один раз загрузите туда публичный USD-Venue-CA.crt с ноутбука. Нажмите «Скопировать ссылку для MAX» и отправьте судьям ссылку. Пересылать файл в мессенджере не нужно. На iPhone откройте страницу в Safari.

Все устройства — в одной Wi-Fi-сети. Для входа судей: https://IP-ноутбука/login. Для телевизора без сертификата: http://IP-ноутбука/venue/live. Табло выводит только настоящие результаты из локальной базы, отдельно SPL и BFSPL + BDW SPL; классы переключаются каждые 9 секунд.

Только если нужно работать судьёй с телефона через HTTPS: после запуска нажмите «Получить сертификат для судей». Программа до 30 секунд ожидает CA от Caddy и положит публичный файл USD-Venue-CA.crt в основную папку USD-Offline-Windows и в local-private. Отпечаток SHA-256 указан в журнале операции. Приватный ключ CA не копируется.

Откройте основную онлайн-админку USD → Офлайн-сервер → Сертификат HTTPS, один раз загрузите оттуда публичный USD-Venue-CA.crt с ноутбука, сверьте SHA-256. Теперь судьи могут скачать .cer для iPhone или .crt для Android из админки или по QR, без паролей и специальных программ. На iPhone: Safari → «Профиль загружен» → «Установить», затем «Основные» → «Об этом устройстве» → «Доверие сертификатам». На Android: настройки безопасности → установка CA. Доверяйте только проверенному корневому сертификату вашего ноутбука.

Проверьте регистрацию, инспекцию, ввод результата, LIVE, перезагрузку Windows и работу без интернета.

5. Сохраните и отправьте результаты

«Сохранить резервную копию» создаёт защищённый файл и открывает папку с копиями. Для шифрования используется ключ этапа. Вводить новый пароль не требуется.

«Отправить результаты на сайт» временно приостанавливает судейский ввод, сохраняет копию и ждёт, пока центральный сервер подтвердит журнал и пересчёт результатов. При сетевой ошибке можно повторить отправку. Сервер продолжит работу на площадке, если до операции судейский ввод был включён.

6. Загрузите следующий этап

Войдите в USD, выберите другой опубликованный этап и нажмите «Загрузить этап». Перед переключением программа проверит локальную базу и сделает зашифрованную копию. Предыдущие результаты останутся в той же базе.

Откройте «Архив этапов», чтобы найти копии, сохранить резервную копию выбранного этапа или отправить его результаты позднее. Доступ к автоматической отправке ограничен сроком ключа этапа. После переключения судьям потребуется снова войти в USD. Сертификат прежний, пока используется тот же ноутбук и удостоверяющий центр.
