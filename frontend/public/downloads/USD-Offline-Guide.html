USD — настоящий офлайн-этап

Простая инструкция для администратора и судей. Печать из браузера: Ctrl + P.

Перед официальным этапом: обязательно испытайте ноутбук, роутер и два телефона с отключённым интернетом и проверьте возврат результатов на Ubuntu. Не удаляйте данные до подтверждённого переноса.

1. Скачайте три файла из админки USD

  1. Откройте основной USD → «Офлайн-сервер» → «Подготовка файла настоящего этапа».
  2. Выберите нужный опубликованный этап и скачайте .json, затем отдельно .key и .pem.
  3. Сохраните отпечаток Ed25519 с этой же защищённой страницы. Пакет действует 72 часа. Никому не отправляйте ключ .key.

2. Обновите программу и уберите старый пробный сервер

Скачайте «USD для Windows» и извлеките ZIP. Если раньше запускали пробный сервер, скопируйте все файлы новой программы в прежнюю папку с заменой. Сохраните файлы .env и папку local-private до запуска установщика.

Дважды нажмите USD-Install.cmd. При обнаружении завершённой старой пробной базы программа предложит её безвозвратно удалить. Подтверждайте только если эти данные больше не нужны. Настоящий этап и чужие Docker-тома удаляться не будут.

3. Установите настоящий этап

  1. Подключитесь к судейскому роутеру. Сеть Windows — «Частная», Docker Desktop запущен.
  2. В мастере выберите адаптер Wi-Fi. Разрешите локальный HTTPS-порт 443.
  3. Выберите подписанный файл этапа .json и открытый ключ .pem.
  4. Введите независимый отпечаток подписи из админки, затем выберите закрытый файл доступа судей .key.
  5. Подтвердите импорт и откройте показанную страницу входа.

Администратор и судьи входят под обычными учётными записями USD. Отдельные тестовые пароли не нужны.

4. Откройте на телефонах и LIVE-табло

Все устройства — в одной Wi-Fi-сети. Вход: https://IP-ноутбука/login. LIVE: https://IP-ноутбука/venue/live.

Для HTTPS используйте только публичный сертификат local-private/USD-Venue-CA.crt с вашего ноутбука. На iPhone: «Настройки» → «Профиль загружен», затем «Основные» → «Об этом устройстве» → «Доверие сертификатам». На Android установите CA в настройках безопасности. На Windows установите CA в доверенные корневые центры текущего пользователя.

Проверьте регистрацию, инспекцию, ввод результата, LIVE, перезагрузку Windows и работу без интернета.

5. Возврат на Ubuntu

USD-Export.cmd создаёт резервный зашифрованный возвратный файл — это ещё не синхронизация. USD-Online.cmd делает защищённый возврат, сверяет подтверждение Ubuntu и только после него останавливает локальный сервер.

Не удаляйте .env, local-private и Docker-тома с настоящими данными, пока центральные результаты не проверены.

6. Следующий этап — без удаления результатов

Перед новым соревнованием скачайте его свежий подписанный пакет .json, ключ судей .key, открытый ключ .pem и отпечаток из основной админки USD.

  1. Нажмите USD-Next-Stage.cmd либо ярлык «USD — Следующий этап» на рабочем столе текущего этапа.
  2. Выберите JSON нового этапа. Программа остановит судейский ввод и проверит точное подтверждение последнего журнала на Ubuntu; если есть новые записи, сначала синхронизирует их.
  3. После успешного подтверждения программа сохранит старую базу и тома, затем создаст отдельную папку и Docker-проект для нового этапа.
  4. Укажите PEM, отпечаток из основной админки и ключ .key. После установки ярлыки будут вести на новый этап.

Предыдущие результаты не стираются. Каждый этап имеет отдельную PostgreSQL и отдельные Docker-тома. Ошибка синхронизации блокирует переключение. Если новая установка не завершилась, повторите USD-Install.cmd в новой папке. Не удаляйте старый Docker-проект и папки с ключами.

Новый этап не импортируется в старую базу. Одновременно можно запускать только один локальный HTTPS-сервер. Это не заменяет резервное копирование ноутбука.
