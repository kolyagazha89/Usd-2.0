# Ошибки рядом с действием и поиск при регистрации на месте

Связано с #114: регистрация на площадке, инспекция, судейство и удобство конфигуратора.

При пустом поиске регистрация на месте больше не выводит профили и не предлагает
раскрыть всю базу. Поиск по ФИО, команде и телефону и выбранный профиль сохранены.

Ошибки валидации и API показываются у кнопок создания профиля/автомобиля,
регистрации, сохранения конфигурации, добавления оборудования, изменения классов,
подтверждения оборудования, отказа в допуске и сохранения измерения.
Независимые операции имеют отдельные сообщения, чтобы параллельная загрузка
справочника не отправляла ошибку записи к другой кнопке.

Регрессионная проверка: `frontend/test/inline-form-errors.test.mjs` монтирует
реальные React-компоненты в JSDOM с синтетическими данными и заменой границы API.
Проверяет пустой/очищенный поиск, клиентскую валидацию госномера, отказы API
при создании профиля/автомобиля/регистрации, отказ инспекции, конфигуратор
и расположение сообщения в редакторе измерения. Записи в настоящую БД не выполняются.

Локальная проверка: `cd frontend && npm test` и `npm run build`.
Статусы CI, слияния, развёртывания и приёмки на физических устройствах
фиксируются отдельно в PR и #114; JSDOM не доказывает мобильную визуальную приёмку.
