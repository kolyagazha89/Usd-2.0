## Что нельзя считать полностью проверенным

- Админские и судейские рабочие процессы не входили в уточнённую пользователем область публичной части. Их CSS попал в статический проход, визуальное покрытие админки здесь не заявляется.
- Не воспроизведены все права/роли, реальные Push-разрешения, фотографии всех пропорций, реальная загрузка файлов, pending-equipment после истёкшего срока, успешные ссылки смены пароля/email, все сетевые ошибки и каждое состояние каждого контрола.
- Нет полного прохода200% zoom, реальных iOS/Android и всех браузеров. Непроверенное не помечено как «без багов».
- Геометрический скан не заменяет просмотр: CSS-11 был найден hit-test, CSS-13 — отдельными измерениями абзацев, CSS-14 — проверкой внутренней вертикальной прокрутки, CSS-15 — contrast. Нулевая колонка overflow у контролов не означает исправность экрана.

## Инструменты и сохранность результата

Бесплатные локальные Stylelint и axe-core, установленный Impeccable detector, методика Product Design, IAB/CDP для computed styles, геометрии, hit-test и скриншотов. Платные внешние проверки не запускались. JSON remaining-screen-matrix.json содержит измерения, включая явно названные предварительные/пустые состояния. Имена файлов снимков соответствуют состояниям таблицы.

Тестовый контент news/partners/contacts/legal восстановлен; временные onboarding user/team/posts/memberships удалены и это проверено запросами. Основной файл багов: USD-public-CSS-bugs.md. Архив доказательств: USD-public-CSS-audit.zip.
