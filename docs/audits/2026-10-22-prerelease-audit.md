# USD: углублённый предрелизный аудит, 22 октября 2026

## Решение о готовности

**Полный запуск пока не рекомендован.** Подтверждённые ниже программные дефекты исправлены в кандидате. Организатору необходимо заменить опубликованные заглушки юридических документов и сведения о ближайшем этапе. Выпуск исправлений не означает, что содержимое сайта готово к релизу.

Это расширение проверки Product Design: дополнительно проверены API, права гостя, публикация данных, сбои запросов, зависимости, сборки и сценарии с авторизованным участником. Нагрузочный тест, внешний пентест, реальные Safari/iOS/Android и доставка писем не подменяются этим аудитом.

## Исходная версия и методы

- Начало: `main` / `67727f9182f76f8f1ea5a081360e34e9cb6aafcb`.
- Сайт: https://usd-2-0.ultimatesounddestruction.workers.dev
- API: https://usd-api-production.up.railway.app
- Свежая проверка Chrome: гость, затем реальная учётная запись участника через защищённый вход. Регистрации, согласия, личные данные и автомобили не изменялись.
- Сценарии кандидата в CI используют синтетические ответы API и не доказывают доступность production API. Ширины: 320, 390, 1024, 1440 px.
- Снимки и результаты этой проверки сохраняются отдельно от предыдущего визуального отчёта. Проверка ошибочного URI в облачном браузере ограничена: инструмент экранирует `%`, поэтому сам сбой подтверждён исполнением реального React-приложения в регрессионном тесте.

Юридическая экспертиза документов, нагрузочные пороги, сроки восстановления из резервной копии и внешняя проверка безопасности не выполнялись. Работа публичных экранов не доказывает эти свойства.

API CORS: разрешённый origin сайта получает Access-Control-Allow-Origin; посторонний origin не получает разрешения. API отдаёт CSP, HSTS, nosniff, X-Frame-Options и no-referrer. У frontend отсутствующие заголовки добавлены в кандидате.

## Статус кандидата

Локальные проверки указаны выше. Результаты свежего PR CI, мобильные артефакты, ревью и проверка опубликованной версии должны быть проверены перед слиянием. Итоговый пользовательский отчёт дополняется ими после выполнения.
