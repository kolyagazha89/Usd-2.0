# USD — выпуск отдельного согласия на публикацию официальных протоколов (16.11.2026)

Статус: **DRAFT / НЕ ДЕПЛОИТЬ КАК ГОТОВЫЙ РЕЛИЗ**.

В PR #588 код запрещает подтверждать отдельное согласие и подавать новую заявку без опубликованного утверждённого DOCX категории `officialProtocolConsent`. Исторические официальные протоколы (ФИО + результат) не мигрируются и не скрываются.

## Выполнено в коде
- `Профиль → Согласия`: отдельная версия, время, отзыв, аудит и ссылка на утверждённый текст.
- Приём новой заявки участником и сотрудником проверяет отдельное согласие на сервере.
- Админка юридических документов позволяет загрузить, предварительно прочитать и опубликовать DOCX `officialProtocolConsent`.
- Ссылка `/documents/officialProtocolConsent` открывает адаптивный ридер без Word.
- Обновлены unit/frontend/e2e тестовые сценарии.

## Обязательные действия до слияния и выпуска
1. Проверить и заполнить **реальный полный адрес** и реквизиты ИП, единый email для запросов по ПДн, название действующего домена. Не утверждать поля-заглушки `1`, `2`, `[...]`.
2. Юридически согласовать отдельный текст по ст. 9 и ст. 10.1 № 152-ФЗ, перечень категорий, условия/запреты субъекта, срок, отзыв, несовершеннолетних, практику получения согласия на площадке и вопрос обязательности публикации для допуска.
3. Загрузить DOCX в «Админка → Юридические документы → Согласие на публикацию официальных протоколов». **Загрузка сбрасывает прежнее юридическое утверждение**. Просмотреть все документы и утвердить новую редакцию в CMS.
4. Проверить не только факт наличия DOCX, но и его фактическое публичное открытие через API и ридер в iOS.
5. Пройти GitHub Actions: Backend CI, Frontend CI, Competition journey, Public browser QA, Home PC safety, Venue LAN. Подтвердить миграцию на копии БД, после деплоя проверить release SHA на Ubuntu.
6. Проверить учёт требований субъектов об ограничении распространения и обработку исторических протоколов на отдельном основании. Согласовать сведения для РКН.
7. Не сливать конкурирующие PR #581/#585 без объединения моделей и миграций.

## Замечание
Тестовая защита срабатывает при отсутствии прикреплённого утверждённого DOCX. Она **не** доказывает, что содержание договора, категории, ограничения и процедуры соответствует закону. Факт публикации старых результатов во «ВКонтакте» сам по себе не заменяет правового основания.
