## Подтверждённые проблемы и исправления в PR #225

1. **Главная — устаревший слоган.** В React был fallback с фразой «КОГДА ЗВУК СТАНОВИТСЯ МОЩНОСТЬЮ», а сервис настроек содержал устаревшее значение заголовка. В PR fallback заменён на `USD`, дефолтный подзаголовок — на «Официальный чемпионат по автозвуку».
2. **Сохранённая настройка главной.** Добавлена отдельная миграция, которая меняет только известные устаревшие значения заголовка в строке настроек по умолчанию; пользовательские заголовки не затрагиваются. Старые применённые миграции не редактировались, чтобы не менять их checksum.
3. **Модальные окна.** В `frontend/src/styles.css` присутствовали множественные конфликтующие правила: часть выравнивала окна к верхнему краю, часть — к нижнему. В PR добавлен финальный override для центрирования на разных ширинах и ограничения высоты окна.
4. **Права на контроль данных для пользовательских ролей.** Пункт меню сопоставлялся с модулем `statistics`, а backend-контроллеры проверки качества данных не имели явного сопоставления с матрицей ролей. В PR пункт меню и оба read-only контроллера привязаны к существующему модулю `imports`; добавлены регрессионные тесты для отчёта и dry-run.

PR #225 открыт; изменения не объединены и не развёрнуты. На актуальном head `b90af11c9f51a2716a6fb55be798c062a01a75a7` Backend CI и Frontend CI прошли: Prisma Client generation, миграции, dependency audit, build, lint, unit/E2E; frontend build и Wrangler dry-run. Cloudflare Preview для того же head завершился Failed; детали доступны только в Cloudflare Dashboard и не читаются из текущей сессии.
