# USD — резервная регистрация без электричества

1. Перед выездом закройте онлайн-регистрацию и распечатайте ведомость выбранного этапа: А4, книжная, по ширине одной страницы.
2. Назначьте одного ответственного за номера. Предварительно зарегистрированному выдайте наклейки, указанные в ведомости. Для нового участника используйте минимальный свободный номер с учётом всех занятых строк, запишите ФИО, авто, госномер и классы.
3. Основной номер — не более пяти классов, из них не более одного BassRace; дополнительные BassRace записываются отдельными строками с собственными номерами. Не переиспользуйте выданные номера. Если не хватило 100 строк, продолжите нумерацию.
4. После проверки судья ставит отметку в колонке «Инспекция». Отказ и его причину фиксируйте отдельно; изменения классов и результаты фиксируйте с номером, классом и судьёй. Получите действующие согласия и подтверждение регламента; отметка в ведомости не заменяет согласия.
5. После восстановления работы сначала сверяйте действующие заявки по ФИО и автомобилю. Новых регистрируйте через регистрацию на месте; сайт автоматически выделяет номера. Если бумажный и цифровой номера различаются, запишите соответствие до переноса инспекции и результатов. Не создавайте дублей. Храните оригиналы у ответственного.
