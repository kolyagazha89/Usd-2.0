## Продолжение

- Сохранён выбранный графитовый/красный USD-дизайн, оригинальный логотип и светлая админка.
- Добавлены активные пункты мобильной публичной панели и вложенных страниц верхнего меню.
- Автомобиль и конфигурации сохраняют навигацию ЛК; «Открыть конфигуратор» ведёт сразу к конфигурациям.
- Шапка участника адаптируется одной строкой; обновление и выход имеют отдельные классы и доступные названия.
- Уплотнены заголовки и карточка авто в редакторе, убран повторный заголовок направления и отдельный фон вложенной страницы.
- Высота cookie-баннера измеряется при переносе текста/изменении окна. Резерв прокрутки и кнопка сохранения учитывают баннер и нижнюю панель. Баннер скрыт на время выбора оборудования и диалогов конфигуратора.
- Исправлено существовавшее до этих изменений переполнение карточек админской панели на 320px (2px); тема админки сохранена.

## Проверка и границы

Исходный main: 34 теста проходят, сборка проходит. Исходный браузерный прогон: 127/128; единственный сбой — админская панель 320px, описанный выше.

Новый браузерный прогон проверяет собранные JS/CSS, публичные разделы, ЛК и админку на 320/390/1024/1440px. Дополнительно: семь вкладок редактора, поиск модели, отказ добавления отсутствующей модели, добавление оборудования из каталога в локальный черновик, шапка одной строкой, активные пункты, отсутствие перекрытия навигации/сохранения баннером. Все API в этом прогоне синтетические; записи в рабочую БД не выполняются.

Cloud browser завис при открытии production. Локальная браузерная проверка не подтверждает production-деплой, native iPhone Safari, авторизацию и сохранение в реальную БД. Результат CI/деплоя следует сверить по точному SHA после публикации PR.

Не объединять устаревшие draft PR #284/#285 автоматически. PR #232, импорт и инфраструктурный перенос остаются отдельными задачами.
