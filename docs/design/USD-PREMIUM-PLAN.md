# USD Premium — перенос публичного дизайна

Цель: перенести одобренный интерфейс в существующий React-проект, сохранив реальные данные, вход и кабинет.

1. Осветлить 3D-материалы ближе к оригинальному серебру, сохранить исходный PNG и движение.
2. Исправить сжатие сеток и мобильные таблицы; улучшить карточки, типографику, состояния загрузки, ошибок и отсутствующих данных.
3. Подключить новую главную, навигацию и подвал к действующим публичным API и настройкам сайта; сохранить редакторские переключатели и порядок блоков.
4. Оформить существующие этапы, результаты, рекорды и правила; добавить страницы участников, автомобилей, команд, новостей, партнёров и документов только на опубликованных данных.
5. Проверить тесты фронтенда, сборку и ключевые экраны desktop/mobile. Создать отдельный PR для переноса.

Ограничения: main и БД не изменять; backend, DNS и старый сайт Tilda не менять; не переносить фиктивные результаты, формы, регламенты и партнёров. Реальная регистрация остаётся в существующем кабинете. Публичное переключение домена требует отдельного решения после готового предпросмотра.
