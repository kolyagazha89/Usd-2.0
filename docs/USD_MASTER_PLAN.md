## 1. Главная цель

Полностью завершить разработку официального сайта соревнований по автозвуку **USD (ЮСД)**, перенести его на собственный сервер Ubuntu и обеспечить стабильную, безопасную, автоматическую работу.

**Финальный результат:**

- Современный премиальный сайт мирового уровня.
- Полностью переработанная публичная часть без остатков старого дизайна.
- Удобный личный кабинет участников.
- Полнофункциональная светлая административная панель.
- Полностью работающие регистрации, инспекции, судейство, результаты, рекорды и история соревнований.
- Сохранённая историческая база участников и результатов.
- Безопасное хранение данных и фотографий.
- Автоматический деплой из GitHub.
- Возможность управлять всем сайтом через административную панель.

**Главный принцип:** сайт должен быть полностью готов к реальному использованию, а не просто успешно собираться или красиво выглядеть на скриншотах.

## 2. Инфраструктура и Ubuntu

### Исходные данные

10. Обеспечить безопасное восстановление после сбоя сервера.

### Автоматический деплой

**Цель — как на Railway: отправили изменения в GitHub, и сайт обновился самостоятельно.**

Необходимый процесс:

1. Разработчик отправляет изменения в GitHub.
2. Запускаются проверки CI.
3. GitHub Actions собирает Docker-образы API и frontend.
4. Образы публикуются в GHCR с неизменяемыми SHA-тегами.
5. Ubuntu получает сигнал на обновление через защищённый GitHub Runner.
6. Сервер проверяет результаты CI и соответствие версий.
7. Создаются и проверяются резервные копии.
8. Проверяется совместимость схемы Prisma.
9. Новые контейнеры запускаются без пересоздания базы данных.
10. Проверяются API, frontend и доступность публичного сайта.
11. При ошибке выполняется безопасный откат.
12. Успешное обновление фиксируется в журнале.

Обычные обновления, не требующие отдельного согласования миграций, должны проходить автоматически.
