USD — настоящий офлайн-этап

Простая инструкция для администратора и судей. Печать из браузера: Ctrl + P.

Перед официальным этапом: обязательно испытайте ноутбук, роутер и два телефона с отключённым интернетом и проверьте возврат результатов на Ubuntu. Не удаляйте данные до подтверждённого переноса.

1. Скачайте три файла из админки USD

  1. Откройте основной USD → «Офлайн-сервер» → «Подготовка файла настоящего этапа».
  2. Выберите нужный опубликованный этап и скачайте .json, затем отдельно .key и .pem.
  3. Сохраните отпечаток Ed25519 с этой же защищённой страницы. Пакет действует 72 часа. Никому не отправляйте ключ .key.

2. Обновите программу и уберите старый пробный сервер

Скачайте «USD для Windows» и извлеките ZIP. Если раньше запускали пробный сервер, скопируйте все файлы новой программы в прежнюю папку с заменой. Сохраните файлы .env и папку local-private до запуска установщика.

Если настоящий этап уже работает: не удаляйте .env, папку local-private и Docker-тома. Скопируйте файлы нового ZIP в ту же папку с заменой программы и запустите USD-Install.cmd при доступном интернете. Мастер скачает проверенную текущую версию интерфейса и обновит существующий frontend и шлюз — без второго Docker-контейнера. API, база, номера, участники и результаты останутся прежними. Интерфейс судей обновится вместе с LIVE. USD-Offline.cmd лишь запускает установленную версию и не выполняет обновлений по сети.

Дважды нажмите USD-Install.cmd. При обнаружении завершённой старой пробной базы программа предложит её безвозвратно удалить. Подтверждайте только если эти данные больше не нужны. Настоящий этап и чужие Docker-тома удаляться не будут.

3. Установите настоящий этап

  1. Подключитесь к судейскому роутеру. Сеть Windows — «Частная», Docker Desktop запущен.
  2. В мастере выберите адаптер Wi-Fi. Разрешите локальный HTTPS-порт 443.
  3. Выберите подписанный файл этапа .json и открытый ключ .pem.
  4. Введите независимый отпечаток подписи из админки, затем выберите закрытый файл доступа судей .key.
  5. Подтвердите импорт и откройте показанную страницу входа.

Администратор и судьи входят под обычными учётными записями USD. Отдельные тестовые пароли не нужны.

4. Откройте на телефонах и LIVE-табло

Все устройства — в одной Wi-Fi-сети. Для входа судей: https://IP-ноутбука/login. Для телевизора без сертификата: http://IP-ноутбука/venue/live (не старая ссылка на HTTPS). При переходе по старой HTTPS-ссылке программа перенаправит на новый ТВ-экран. Табло выводит только настоящие результаты из локальной базы, отдельно SPL и BFSPL + BDW SPL; классы переключаются каждые 9 секунд.

Только если нужно работать судьёй с телефона через HTTPS: после запуска USD дважды нажмите USD-Certificate.cmd или ярлык «USD — Сертификат». Программа до 30 секунд ожидает CA от Caddy и положит публичный файл USD-Venue-CA.crt в основную папку USD-Offline-Windows и в local-private. В консоли выведен SHA-256 сертификата. Приватный ключ CA не копируется.

Откройте основную онлайн-админку USD → Офлайн-сервер → Сертификат HTTPS, один раз загрузите оттуда публичный USD-Venue-CA.crt с ноутбука, сверьте SHA-256. Теперь судьи могут скачать .cer для iPhone или .crt для Android из админки или по QR, без паролей и специальных программ. На iPhone: Safari → «Профиль загружен» → «Установить», затем «Основные» → «Об этом устройстве» → «Доверие сертификатам». На Android: настройки безопасности → установка CA. Доверяйте только проверенному корневому сертификату вашего ноутбука.

Проверьте регистрацию, инспекцию, ввод результата, LIVE, перезагрузку Windows и работу без интернета.

5. Возврат на Ubuntu

USD-Export.cmd создаёт резервный зашифрованный возвратный файл — это ещё не синхронизация. USD-Online.cmd делает защищённый возврат, сверяет подтверждение Ubuntu и только после него останавливает локальный сервер.

Не удаляйте .env, local-private и Docker-тома с настоящими данными, пока центральные результаты не проверены.

6. Следующий этап — та же база и Wi-Fi

Заранее скачайте пакет нового этапа .json и ключ судей .key. Нажмите USD-Next-Stage.cmd или ярлык «USD — Следующий этап», выберите JSON и ключ.

Программа сохранит возвратный файл предыдущего этапа и добавит новый в ту же локальную базу. Участники, автомобили, старые регистрации и результаты сохраняются. Повторно устанавливать сертификат на телефоны не требуется. Передача на основной сервер для перехода не нужна: её можно сделать позже.

При первом запуске нового этапа войдите заново обычным email и паролем USD. Если установка прервалась, откройте USD-Install.cmd в новой папке stage-workspaces/UUID, указанной программой. Не удаляйте исходную папку USD, .env, local-private или Docker volumes.

Кнопки Экспорт и Онлайн в папке этапа выгружают только его данные. Старый этап можно отправить позднее из его прежней папки; текущий сервер при этом продолжает работать. Автоматический доступ к отправке действует 30 дней с подготовки пакета. Локальное хранение не заменяет копию на другом устройстве.
