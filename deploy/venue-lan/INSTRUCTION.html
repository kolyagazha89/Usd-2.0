Офлайн-сервер на ноутбуке

Сохраните эту инструкцию. Она открывается без интернета. Для печати нажмите Ctrl + P в браузере.

Сейчас — для пробного запуска.
Перенос результатов с ноутбука на основной сервер ещё не завершён. Сначала проверьте ДЕМО с вымышленными участниками. До завершения переноса и проверки двух телефонов без интернета настоящий этап здесь проводить нельзя.

Что понадобится

  • Отдельный ноутбук с Windows 10 или 11 и блоком питания.
  • Wi-Fi-роутер, к которому подключатся ноутбук и все телефоны. Лучше заранее закрепить постоянный IP ноутбука в настройках роутера.
  • Интернет дома для первой установки. На площадке скачивать программу уже не потребуется.

Все действия выполняйте на ноутбуке площадки. Центральную Ubuntu USD не трогайте.

1. Скачайте и распакуйте

  1. В админке USD откройте «Соревнования» → «Офлайн-сервер».
  2. Нажмите «Скачать для Windows».
  3. Найдите архив USD-Offline-Windows.zip в папке «Загрузки».
  4. Нажмите на архив правой кнопкой мыши → «Извлечь всё». Выберите постоянную папку на ноутбуке.
  5. Откройте извлечённую папку USD-Offline-Windows. Запускать программу прямо внутри архива нельзя.

После установки папку не перемещайте и не переименовывайте: ярлыки ссылаются на неё.

2. Установите один раз дома

  1. Включите интернет и подключите ноутбук к тому роутеру, который возьмёте на площадку.
  2. Для этой сети в Windows выберите профиль «Частная». В роутере отключите изоляцию Wi-Fi-клиентов, если она включена.
  3. Дважды нажмите USD-Install.cmd.
  4. Если установщик предложит Docker Desktop — согласитесь. Откройте установленный Docker Desktop, завершите его настройку с Linux containers / WSL2. Если потребуется перезагрузка, перезагрузитесь и снова нажмите USD-Install.cmd.
  5. Выберите подключение ноутбука к роутеру. Адрес предложит сама программа, печатать его вручную не нужно.
  6. Выберите «ДЕМО — пробный запуск без настоящих участников».
  7. Когда Windows спросит разрешение на настройку брандмауэра — нажмите «Да».
  8. Задайте пароли администратора и судьи. Каждый пароль: не менее 16 символов латиницей, с большой и маленькой буквами, цифрой и знаком. Сохраните пароли в надёжном месте.
  9. Дождитесь сообщения «USD запущен». Первая установка скачивает сервер и может занять время. Не закрывайте окно во время работы.

Откроется страница входа. На рабочем столе появятся ярлыки «USD — Офлайн», «USD — Онлайн», «USD — Экспорт» и «USD — Инструкция».

Если установка прервалась: устраните причину и снова нажмите ту же кнопку установки. Данные и завершённые шаги сохраняются. Папки и данные Docker не удаляйте.

3. Подключите телефоны

  1. Телефоны и ноутбук подключите к одному Wi-Fi. При испытании отключите мобильные данные телефонов, чтобы убедиться в работе без интернета.
  2. Программа покажет два адреса: «Вход» и «Табло». Используйте именно их, а не обычный адрес сайта USD.
  3. В папке программы откройте local-private. Найдите USD-Venue-CA.crt — публичный сертификат локального сервера. Передайте его на телефоны доверенным способом. Другие файлы этой папки не передавайте.
  4. На iPhone: откройте сертификат → «Настройки» → «Профиль загружен» → «Установить». Затем «Основные» → «Об этом устройстве» → «Доверие сертификатам» → включите полное доверие к сертификату вашего локального сервера.
  5. На Android: настройки безопасности → установка CA-сертификата. Название пункта зависит от модели. Принимайте только сертификат со своего ноутбука.
  6. На ноутбуке сертификат тоже нужно доверить: дважды щёлкните по USD-Venue-CA.crt → «Установить сертификат» → «Текущий пользователь» → «Поместить все сертификаты в следующее хранилище» → «Доверенные корневые центры сертификации».

Перед установкой доверия проверьте, что сертификат получен именно с подготовленного вами ноутбука. Один запуск программы не может автоматически настроить доверие на чужих телефонах.

Кто входитЛогин
Администраторoperator1@venue.invalid
Судьяjudge-01@venue.invalid

Пароли — те, которые задали при установке. Логины выше относятся только к ноутбуку. Для просмотра LIVE-табло вход не нужен.

4. Проверьте без интернета

  1. В тестовом этапе администратор создаёт вымышленного участника, регистрирует автомобиль и отмечает инспекцию.
  2. Судья на другом телефоне вводит результат. На LIVE-табло он должен появиться примерно за четыре секунды.
  3. Отключите WAN-кабель роутера и мобильные данные телефонов. Повторите действия. Wi-Fi-роутер и ноутбук оставьте включёнными.
  4. Перезагрузите ноутбук, войдите в Windows и дождитесь Docker Desktop. Локальный сервер должен подняться автоматически. Проверьте сохранённые результаты.

В ДЕМО используйте только вымышленные имена и номера автомобилей. Тестовые результаты не переносятся на основной сервер.

Кнопки сервера на каждый день

Включить на площадке

Включите тот же роутер и ноутбук. Дважды нажмите ярлык «USD — Офлайн» или файл USD-Offline.cmd. Интернет для уже установленного сервера не нужен. Не закрывайте Docker Desktop во время соревнований.

Вернуться на сайт

Дважды нажмите «USD — Онлайн» или USD-Online.cmd. Для настоящего этапа программа сначала предложит сохранить защищённый файл результатов и запросит пароль шифрования. Только после успешного экспорта локальный сервер остановится, автозапуск отключится и откроется основной сайт. В ДЕМО переключение выполняется без экспорта.

Это переключение режима, а не отправка результатов.
Все локальные записи останутся на ноутбуке. Для возвращения к ним нажмите «USD — Офлайн». Не удаляйте папку программы, local-private, файл .env или данные Docker до сверки и подтверждённого переноса.

Сохранить результаты после настоящего этапа

В папке программы или на рабочем столе нажмите «USD — Экспорт» / USD-Export.cmd. Эта кнопка доступна только после установки настоящего этапа: ДЕМО нельзя переносить на центральный сервер. На время экспорта программа приостановит ввод результатов. Если вы нажали только «Экспорт», после записи файла судейский сервер снова включится. При ошибке он тоже восстанавливается, результаты в базе остаются.

  1. Программа создаст на ноутбуке отдельную защищённую пару ключей (закрытый ключ не выйдет из Docker-хранилища).
  2. Придумайте отдельный длинный пароль для шифрования. Сохраните его отдельно от файлов.
  3. Откройте папку local-private/return-output. В ней находится зашифрованный файл usd-venue-return-....json, открытый ключ USD-Venue-Return-Public.pem и отпечаток USD-Venue-Return-Fingerprint.txt.
  4. Передайте зашифрованный файл ответственному администратору, а пароль сообщите отдельным способом. Сверьте отпечаток ключа по независимому каналу. Никому не передавайте закрытый ключ и папки с секретами.
  5. После получения подтверждения переноса всех записей и проверки центральных результатов администратор разрешит завершить работу. До этого не удаляйте локальные файлы, базу и Docker-тома.
«Экспорт» не означает «Синхронизировано». Программа создаёт защищённый файл для сверки и переноса. Новые профили, регистрации, изменения конфигураций и фотографии пока требуют отдельного согласования на Ubuntu. Если в отчёте есть конфликты или необработанные операции, продолжайте хранить весь локальный журнал.

Если что-то не получилось

  • Не открывается на телефоне: проверьте общий Wi-Fi, частный профиль сети Windows, отсутствие изоляции клиентов и доверие к сертификату.
  • После перезагрузки сервер не появился: войдите в Windows, откройте Docker Desktop, дождитесь его готовности и нажмите «USD — Офлайн».
  • Сменился адрес ноутбука: верните адрес, выбранный при установке, в настройках роутера. Не переустанавливайте поверх сохранённых результатов.
  • Установщик сообщает об ошибке: прочитайте причину в окне. Ничего не удаляйте. Сохраните текст ошибки для ответственного за сайт; пароли и файл .env ему в переписке не отправляйте.

Настоящий этап: предварительная подготовка

Когда будет готов перенос результатов и пройдёт проверка на оборудовании, используйте в админке блок «Подготовка файла настоящего этапа». Скачайте файл этапа и открытый ключ. Файл действует 72 часа и содержит данные участников — не размещайте его в общем доступе.

В установщике выберите подписанный этап, укажите оба файла через окна выбора. Отпечаток ключа копируйте с защищённой страницы админки USD, а не из файла этапа. Установка не меняет центральную базу. При отсутствии настройки подписи админка сообщит об этом; ДЕМО останется доступно.
